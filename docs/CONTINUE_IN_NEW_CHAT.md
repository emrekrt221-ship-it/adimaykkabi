# Continue development in a new ChatGPT conversation

Copy and paste this into a **new** chat with your GitHub connector enabled:

> GitHub'daki **emrekrt221-ship-it/adimaykkabi** projesinin geliştirmesine kaldığı yerden devam et. Önce `AGENTS.md`, `docs/STATUS.md`, `docs/SESSION_HANDOFF.md` ve `docs/MASTER_PLAN_FULL.md` dosyalarını oku; açık PR'ları, dalları ve Issues'ları kontrol et. Kod yazmadan önce mevcut durumu özetle. Ardından sıradaki işi bir feature dalında geliştir, gerçek testleri çalıştır, PR oluştur; bittiğinde STATUS ve SESSION_HANDOFF dosyalarını güncelle. Eski işleri tekrar oluşturma, ana dala izinsiz/incelemesiz merge etme, gizli anahtarları commit etme. Yasal uygunluğu doğrulanmamış taklit markalı ürünler için satış açma. Cloudflare ilk sürümde yok.

## Why this works
All important decisions, progress and next steps live in GitHub rather than the context window of a chat. A different chat/model can reconstruct them from the repo. **It does not automatically execute in the background or start itself when limits renew.**
