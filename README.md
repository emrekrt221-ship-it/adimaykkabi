# ADIM AYAKKABI

Professional mobile-first single-store footwear ecommerce project.

## Stack
WordPress + WooCommerce, lightweight custom theme, MySQL, HPOS, HTTPS, server caching. No Cloudflare in v1.

## Start here
Read `AGENTS.md`, `docs/MASTER_PLAN.md`, `docs/STATUS.md`, and `docs/SESSION_HANDOFF.md` before making changes.

## Important
Only list products legally authorized for sale. Do not publish counterfeit trademarked merchandise or misleading authenticity claims.
