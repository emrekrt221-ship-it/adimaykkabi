# ADIM AYAKKABI

Professional mobile-first single-store footwear ecommerce project.

## Stack
WordPress + WooCommerce, lightweight custom theme, MySQL, HPOS, HTTPS, server caching. No Cloudflare in v1.

## Active development
**First read [CURRENT_DEVELOPMENT.md](CURRENT_DEVELOPMENT.md)** for the latest feature branch, stacked pull requests, test evidence, and cross-chat handoff. The main branch is not the complete in-progress storefront.
