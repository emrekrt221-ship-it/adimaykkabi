# Agent instructions

1. Read docs/MASTER_PLAN.md, ROADMAP.md, DECISIONS.md, STATUS.md and SESSION_HANDOFF.md first.
2. Inspect repository before edits; make focused commits; never claim tests passed without running them.
3. Keep WooCommerce core and vendor dependencies out of git. Implement custom behavior in isolated theme/plugin code.
4. Update STATUS.md and SESSION_HANDOFF.md after every development session with changes, test results, blockers and next action.
5. Never commit secrets, customer data or production credentials. Do not activate checkout until payment and compliance checks pass.
6. Do not build sales listings or checkout workflows for counterfeit trademarked products. Only authorized inventory may be published.
7. Preserve existing work; use branches and PRs for nontrivial changes.
